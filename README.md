# 🍔 Sigma Foods – "More Than Food, It's an Experience"

> Modern, premium 3D Food E-Commerce Platform for Sigma Foods Cafe & Restaurant (Rohini, Delhi).

---

## ✨ Features

- **Cinematic 3D Hero Section**: Layered multi-tier mouse parallax (1x ambient glow, 2x floating ingredients, 4x gourmet platter, 6x foreground particles), neon script calligraphy, floating badges, and continuous scroll indicator.
- **Docked Popular Categories**: Shelf with 7 photographic food categories (Momos, Burger, Pasta, Cigar Rolls, Sandwich, Fries, Beverages).
- **Responsive Across All Devices**:
  - 📱 **Mobile Phone**: Touch-snap horizontal carousel, app-like bottom navigation, GPU accelerated 60fps scrolling.
  - 📲 **Tablet**: 4-column category grid, responsive modals and quick view.
  - 💻 **Laptop / Desktop**: Floating capsule glassmorphism navbar, multi-layer parallax depth.
- **Complete E-Commerce Flow**:
  - Full Menu with category filtering, instant search, price filter, sorting.
  - Quick View modal & dedicated product details pages.
  - Wishlist & Cart drawer with coupon codes (`SIGMA10`, `SIGMA20`) and free delivery milestone bar.
  - Checkout flow with COD / UPI / Cards, order tracking, order history, and account settings.
  - Admin Dashboard (`/admin`) for live analytics, order status updates, and inventory toggle.
- **Fast Performance**:
  - Code-splitting with Rollup `manualChunks` (vendor-react, vendor-motion, vendor-icons, vendor-utils).
  - CSS `content-visibility: auto` on below-the-fold sections.
  - Production build in ~2 seconds.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Glassmorphism + Custom CSS Variables
- **Animations**: Framer Motion
- **State Management**: Zustand with persistent storage
- **Icons**: Lucide React
- **Notifications**: React Hot Toast

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
